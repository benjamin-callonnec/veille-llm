# Plan 5 — Web catalogue (issues #3, #8, #11, #10)

**Goal:** replace the v0 page by a React catalogue that reads `catalogue.json` (hook in bold, brief,
dynamic category chips, type filter, search, sort), deployed by `daily.yml`.
**Spec:** `docs/superpowers/specs/2026-11-21-veille-llm-design.md` sections 5.2 and 8.
**Stack:** Vite + React + TypeScript, Vitest, lockfile (`npm ci`). English only. Papier (light) / Nuit (dark) via `prefers-color-scheme`, no toggle.

## Decisions (author: option A for filters; the rest are my calls)
- Chips: the 7 most frequent categories, the rest in a "+N" menu; multi-select (union); counts follow the other filters; "Other" always last.
- Type filter: Paper / News / Benchmark (union). Sort: Trending (HF upvotes, then score) / Date / Score.
- Search is client-side on title, hook, brief and category. State lives in the URL hash (`#cat=A,B&type=paper&sort=date&q=x`).
- Card: title (link), hook in bold, brief, then category, type, date, score, upvotes. The raw abstract is never shown.
- Catalogue URL: `VITE_CATALOGUE_URL`, default `catalogue.json` (same origin). Links are shown only if `http(s)`.
- Fallback category is "Other" (was "Autres"); existing databases are migrated.
- The v0 code (`site/`, `build.py`, `arxiv.py`, `hf.py`, `topics.py`, `veille-llm` script) is removed: the pipeline core is the only source.

## Tasks (each: failing test first, commit on `develop`)
1. **"Other" fallback** — `FALLBACK_CATEGORY = "Other"`; `Store` migrates "Autres" in `enrichments` and `categories`.
2. **Scaffold `web/`** — Vite React TS, Vitest, `npm run check` = `tsc --noEmit` + `vitest run`; Makefile `web-check` added to `make check`; `.gitignore` node_modules, dist; stop hook also reacts to `web/` changes.
3. **Pure logic `web/src/catalogue.ts`** — `parseCatalogue`, `applyFilters`, `sortItems`, `chipCategories`, `countsByCategory`, `readHash`/`writeHash`, `safeUrl`. Unit tests for each (including URL sanitising, unknown categories in hash, "Other" last, counts following other filters).
4. **UI** — `App`, `Filters`, `Card`, styles with Papier/Nuit tokens, mobile layout, accessible chips (buttons with `aria-pressed`). Component tests for: hook rendered in bold, no raw abstract, chip toggling updates the list, empty state, loading and error states.
5. **Deploy + cleanup** — `daily.yml` deploy job builds `web/` (setup-node, `npm ci`, `npm run build`), copies `catalogue.json` into `dist`, uploads `dist`; `ci.yml` runs `web-check` and build; remove v0 code and tests; update README and workflow tests.
6. **Review + release** — independent opus review, fixes, changelog, v0.5.0, merge to `main`, ask before push.

## Review focus
Untrusted text in cards (no HTML injection, no `javascript:` links); empty/missing fields in old catalogue items (no `brief`); category renamed or missing between days with a stale hash; very long titles on mobile; dark/light contrast.
